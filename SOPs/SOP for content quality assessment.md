# SOP: Content Quality Rubric

---

## Purpose

This Standard Operating Procedure defines the evaluation checklist for all published content. Use this rubric before submitting any article for final review or publishing.

---

## 1. Structure & Format

|---|---|---|---|---|---|

## 2. SEO & GEO

| Category | Criteria | Y | N | N/A | Comments |
|---|---|---|---|---|---|
| Primary Keyword | Primary keyword confirmed and appears in: H1, URL slug, first 100 words, meta title, meta description, image alt text, and at least one H2. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Keyword in Title | Title (H1) is keyword-rich, written for humans first. Max 60 characters. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Meta Title | Meta title is 55–60 characters and contains the primary keyword. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Meta Description | Meta description is 140–155 characters and contains the primary keyword. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| URL Slug | URL slug: max 60 chars, lowercase, hyphen-separated, contains primary keyword. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Keyword Placement | Primary keyword does NOT appear inside parentheses () anywhere in the article. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Keyword Density | Primary keyword density is 1–1.5%. No keyword stuffing. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Secondary Keywords | Up to 3 secondary keywords naturally placed in H2s, body, and FAQ section. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Semantic / NLP | Semantic and NLP keywords included throughout (entity mentions, related topic terms). | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Internal Links | 5 to 8 internal links included. Descriptive anchor text used. Never 'click here'. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| External Links | 2 to 4 external links to credible authority sources only. All external links have rel="nofollow" attribute. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Schema Markup | Schema markup flagged for dev team: Article, FAQ, Howto, Breadcrumb, Author (as applicable). | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Breadcrumbs | Proper breadcrumb structure used: HOME > BLOG > CATEGORY > Article Title. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| Publication Date | Publication date included. 'Last Updated' label added if this is a revised piece. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| GEO: Language | Content written in factual, quotable language. Direct, specific, and structured (not vague or hedging). | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| GEO: Definitions | Technical terms and acronyms defined on first use. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
| GEO: AI Answers | Key points are structured to be lifted as standalone AI answers. Answer not buried mid-paragraph. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |

| Category | Criteria | Y | N | N/A | Comments |

| FAQ Links | Internal links included in answers where relevant. | <input type="checkbox"> | <input type="checkbox"> | <input type="checkbox"> | |
