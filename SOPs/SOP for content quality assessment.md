# SOP: Content Quality Rubric

---

## Purpose

This Standard Operating Procedure defines the evaluation checklist for all published content. Use this rubric before submitting any article for final review or publishing.

---

## 1. Structure & Format

| Category | Criteria |
|---|---|
| Word Count | Word count meets target: Blog 1,200 / Guide 2,000 / Pillar 3,000 / Page 300–500 |    |
| Article Order | All required sections present in correct order: Title → Meta Title → Meta Description → URL → Intro → ToC (if needed) → Body → Conclusion → FAQ → CTA |    |
| Body Sequence | Body follows required sequence: What it is → Why it matters → Core Principles → Strategies → Case Studies → Measuring Performance → FAQs |     |
| Paragraphs | Paragraphs are 2–4 sentences. No large text blocks. |    |
| Headings | H2 / H3 headings used correctly. No skipped heading levels. |    |
| Heading Format | All headings and sub-headings use Title Case (first letter of each word capitalised). |    |
| H2 Format | All H2 headings are descriptive and use interrogative W-question format: What, Why, How, When, Where, Who. |    |
| Images | 3 to 6 images included per article. Every image has a keyword-rich alt tag. Every image has an image caption. |    |
| Engagement | At least one comparison table, statistic, example, or quote included. |    |
| CTA | One CTA only, placed at the end. Newsletter sign-up included if appropriate. |    |

---

## 2. SEO & GEO

| Category | Criteria |
|---|---|
| Primary Keyword | Primary keyword confirmed and appears in: H1, URL slug, first 100 words, meta title, meta description, image alt text, and at least one H2. |    |
| Keyword in Title | Title (H1) is keyword-rich, written for humans first. Max 60 characters. |    |
| Meta Title | Meta title is 55–60 characters and contains the primary keyword. |    |
| Meta Description | Meta description is 140–155 characters and contains the primary keyword. |    |
| URL Slug | URL slug: max 60 chars, lowercase, hyphen-separated, contains primary keyword. |    |
| Keyword Placement | Primary keyword does NOT appear inside parentheses () anywhere in the article. |    |
| Keyword Density | Primary keyword density is 1–1.5%. No keyword stuffing. |    |
| Secondary Keywords | Up to 3 secondary keywords naturally placed in H2s, body, and FAQ section. |    |
| Semantic / NLP | Semantic and NLP keywords included throughout (entity mentions, related topic terms). |    |
| Internal Links | 5 to 8 internal links included. Descriptive anchor text used. Never 'click here'. |    |
| External Links | 2 to 4 external links to credible authority sources only. All external links have rel="nofollow" attribute. |    |
| Schema Markup | Schema markup flagged for dev team: Article, FAQ, Howto, Breadcrumb, Author (as applicable). |    |
| Breadcrumbs | Proper breadcrumb structure used: HOME > BLOG > CATEGORY > Article Title. |    |
| Publication Date | Publication date included. 'Last Updated' label added if this is a revised piece. |    |
| GEO: Language | Content written in factual, quotable language. Direct, specific, and structured (not vague or hedging). |    |
| GEO: Definitions | Technical terms and acronyms defined on first use. |    |
| GEO: AI Answers | Key points are structured to be lifted as standalone AI answers. Answer not buried mid-paragraph. |    |

---

## 3. FAQ Section

| Category | Criteria |
|---|---|
| FAQ Count | FAQ section contains 5 to 8 questions. |    |
| FAQ Sequence | FAQs ordered logically: What / Importance / Principles / Strategies / Case Studies / Measuring, then most common to advanced. |    |
| FAQ Phrasing | All questions use interrogative phrasing: What, Who, How, Why, When, Do, Is, Can, Should. |    |
| FAQ Relevance | All FAQs tied to the primary keyword of the article. No off-topic questions included. |    |
| FAQ Answers | Answers are direct, concise, and 100 words or fewer (exceptions documented). |    |
| FAQ Keyword | Primary keyword does NOT appear inside parentheses () in any FAQ answer. |    |
| FAQ Links | Internal links included in answers where relevant. |    |
| FAQ Schema | FAQ schema markup flagged for dev team. |    |
| FAQ Duplicates | No duplicate information across FAQ answers. |    |

---

## 4. Voice & Tone

| Category | Criteria |
|---|---|
| Active Voice | Active voice used throughout. No passive constructions. |    |
| User Perspective | FAQs and body copy written from the reader's perspective. Uses 'you' and 'your'. |    |
| No Filler Openers | No filler openers: 'In today's digital landscape…', 'Now more than ever…', 'It goes without saying…' |    |
| No Hype Language | No hype language: 'game-changer', 'revolutionary', 'cutting-edge', 'unleash the power of…' |    |
| No Jargon | No unexplained internal jargon. Technical terms defined on first use. |    |
| Plain English | Written in plain English at a level a senior manager can follow. |    |
| Numbers | Numbers one through nine spelled out. Numerals used for 10 and above. |    |
| Brand Voice | The tone is helpful and educational. Sounds like a knowledgeable colleague, not a sales pitch. |    |

---

## 5. Formatting

| Category | Criteria |
|---|---|
| Bold Key Terms | Key terms bolded on first use to aid scanning and reinforce NLP signals. |    |
| Lists | Bullet points or numbered lists used for steps, comparisons, or groups of 3+ items. |    |
| Consistency | Consistent punctuation and capitalisation across all headings and FAQs. |    |
| Mobile | Page confirmed readable and scrollable on mobile screens (no horizontal scrolling). |    |
| No Repetition | No duplicate information across sections. |    |

---

## 6. Review

| Category | Criteria |
|---|---|
| Editorial Review | All editorial comments addressed and resolved. |    |
| SEO/GEO Check | Final SEO & GEO check completed: structure specs met, AI citation signals verified. |    |
| Visual | Visual/infographic created: simple fonts, clean palette, tight spacing, no decorative icons, organisation logo at bottom. |    |
| Distributed | Content shared via social media and newsletter. |    |
| AI Citation Check | AI citation check completed: article monitored for citation in major AI platforms (ChatGPT, Perplexity, Google AI Overviews, etc.). |    |
