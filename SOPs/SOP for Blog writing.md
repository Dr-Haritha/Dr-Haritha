# SOP: Blog Writing

---

## Purpose

This Standard Operating Procedure defines how to write high-quality blog articles that are clear, structured, and optimised for both search engines and AI-driven discovery.

A blog article focuses on **one topic**, explains it clearly, and provides actionable or insightful value to the reader.

---

## 1. Structure & Format

### 1.1 Word Count

**Target:** 1,000–1,500 words  
A blog should be focused, single-topic, and concise while covering the subject in enough depth to be useful.

---

### 1.2 Article Structure

Every blog must follow this structure:

**Flow:**  
What it is → Why it matters → Key ideas → Examples / strategies → FAQs → Conclusion

| Section | Content Requirement | SEO / Technical Spec |
|---|---|---|
| Title (H1) | Clear, keyword-focused headline | Max 60 characters |
| Meta Title | Optimised for search | 55–60 characters |
| Meta Description | Summary that drives clicks | 140–155 characters |
| URL Slug | Short, descriptive | Lowercase, hyphen-separated |
| Introduction | Hook + direct answer in first paragraph | Primary keyword in first 100 words |
| Body (H2 / H3) | Logical sections, one idea per section | Primary keyword in at least one H2 |
| FAQ Section | 5–8 real questions with direct answers | Supports AI extraction |
| Conclusion | Summary only, no new information | — |
| Call to Action | One CTA only, at the end | — |

---

### 1.3 Formatting Rules

**Headings (H2):**  
Use question-based headings:
- What is [Topic]?
- Why does [Concept] matter?
- How does [Process] work?

**Paragraphs:**
- 2–4 sentences max  
- No large text blocks  

**Formatting:**
- Use bullet points for clarity  
- Bold key terms on first use  
- Include at least one:
  - Example  
  - Table  
  - Statistic  

**Images:**
- 2–4 per article  
- Must include keyword-rich alt text  

---

## 2. SEO & GEO

### 2.1 Keyword Planning

Each blog targets:
- **1 primary keyword**
- **Up to 3 secondary keywords**

**Primary keyword must appear in:**
- Title (H1)
- Meta title
- Meta description
- URL
- First 100 words
- At least one H2

---

### 2.2 Optimisation Rules

- Write clear, direct, quotable sentences  
- Define terms on first use  
- Avoid vague or hedging language  
- Structure content so answers can be easily extracted  
- Do not bury key points in long paragraphs  

---

### 2.3 Links

- **Internal links:** 3–5  
- **External links:** 2–3 credible sources  
- Use descriptive anchor text (no “click here”)  

---

## 3. Voice & Tone

| Principle | What This Means |
|---|---|
| Direct | Answer quickly, no fluff |
| Clear | Use simple, plain English |
| Credible | Support claims with examples or data |
| Helpful | Educate first, do not sell |

### Language Rules

- Use active voice  
- Speak directly to the reader (“you”, “your”)  
- Define acronyms on first use  

### Avoid

- “In today’s digital landscape…”  
- “Game-changing”, “revolutionary”  
- Filler or hype language  

---

## 4. Publishing Process

### Workflow

| # | Stage | Detail |
|---|---|---|
| 1 | Keyword Research | Identify search intent and topic |
| 2 | Outline | Define H2s, H3s, and FAQs |
| 3 | Draft | Write full article |
| 4 | Review | Check structure, clarity, and accuracy |
| 5 | Revision | Address feedback |
| 6 | SEO Check | Verify keyword placement and structure |
| 7 | Publish | Finalise and distribute |

---

## 5. Quick Checklist

### Structure
- [ ] Single topic clearly defined  
- [ ] Strong introduction with direct answer  
- [ ] Logical flow (What → Why → How)  
- [ ] 5–8 FAQs included  

### SEO
- [ ] Primary keyword placed correctly  
- [ ] Meta title and description optimised  
- [ ] Internal and external links added  

### Writing
- [ ] No fluff or filler language  
- [ ] Active voice used throughout  
- [ ] Clear and readable formatting  

### Final
- [ ] One CTA at the end  
- [ ] Images added with alt text  
- [ ] Ready for publishing
